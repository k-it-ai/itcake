# Security Policy

## Supported versions

The latest commit on `main`.

## Reporting a vulnerability

Please email **laud3r@me.com**.

Do not open a public issue for security reports. Include the affected version or
commit, reproduction steps, and the impact if you can.

Reports are acknowledged on a best-effort basis. There is no SLA.

## Scope

The entire repository is in scope. Deployment-specific configuration (reverse
proxy, TLS termination, host hardening) is outside the application scope.
